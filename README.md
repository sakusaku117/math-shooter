# けいさん シューティング

5歳から遊べる、宇宙がテーマの計算シューティングゲームです。問題の答えが書かれた隕石・UFO・エイリアンを撃ちます。

`index.html` をブラウザで開くだけで遊べます。インストールや通信は不要です。

## 遊び方

- 画面の上に計算問題が出て、答えの数字が書かれた敵が落ちてきます。
- `←` `→` で宇宙船を動かし、`Enter` か `スペース` で撃ちます。
- 正しい答えを撃つと得点が入ります。間違いを撃つか、正解の敵を下まで通すとハートが1つ減ります(ハートは3つ)。
- 1ステージは10問です。5問目と10問目はボスUFOで、3回正解すると倒せます。
- 問題は音声で読み上げます。問題の枠をクリックすると、もう一度読み上げます。
- タブレットでは画面下に操作ボタンが出ます。

## むずかしさ(↑ ↓ で選ぶ)

| | 問題 | 選択肢 |
|---|---|---|
| 1(5さい〜) | たしざん・ひきざん(こたえが10まで) | 3つ |
| 2(6〜7さい) | たしざん・ひきざん(こたえが20まで) | 4つ |
| 3(8さい〜) | かけざん(九九) | 4つ |
| 4(9さい〜) | わりざん(割り切れる問題) | 4つ |

## はやさ(← → で選ぶ)

🐢 ゆっくり / 🐇 ふつう / 🚀 はやい の3段階です。むずかしさとは別に選べます。

ベストスコアと最後に選んだ速さは、ブラウザの localStorage に保存されます。
